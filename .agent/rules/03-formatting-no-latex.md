# Text Formatting Directive

**NO LATEX MATH FORMATTING:**
1. Never use LaTeX delimiters (such as `$`, `$$`, `\(`, `\)`, `\text{}`, `\times`, `\Omega`) to present values, units, or equations.
2. Always write numbers, formulas, and units using standard plain text formatting (e.g., use `2x 10k ohm`, `500mA`, `3.0V - 4.2V`, `1.0A` instead of LaTeX syntax).
